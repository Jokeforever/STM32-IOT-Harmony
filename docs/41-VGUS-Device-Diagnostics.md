# VGUS 设备诊断

2026-11-17 用户确认本轮实屏验证通过。由首页进入「设备状态」，点左上角「诊断」进入第 17 页。页面显示运行时长、本次复位原因、OneNET 当前状态、各联网阶段的上次结果，以及温湿度与 CO₂ 的采集状态。

## 字段含义

| 字段 | 数据来源 |
|---|---|
| 运行时长 | 主控从启动累计的时间，处理 HAL 毫秒计数回绕 |
| 本次复位 | 启动时读取 STM32 的 RCC 复位标志，保存原因后清除寄存器中的旧标志 |
| AT 应答、获取 IP | 本次启动初始化 ESP8266 时各阶段的最终命令结果 |
| TCP 建连、MQTT 登录 | 启动或重连流程中各阶段最近一次被调用时的结果 |
| OneNET 当前状态 | 主循环的现有 OneNET 连接状态 |
| 温湿度、CO₂ 最近一轮 | 根据已有采集有效位显示待采集、有效或无有效值 |
| 距上次有效 | 从最近一次有效采集起算，无记录显示「--」，满一小时后显示整小时 |

复位标签包括电源、引脚、软件、看门狗、低功耗和未知。看门狗和软件复位等明确标志优先，电源复位优先于引脚复位。 [STM32F1 参考手册 RM0008](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)

「获取 IP 成功」只说明本轮启动连过热点。若运行中掉线，该结果仍可与 OneNET 当前离线同时显示。原 OLED 的 Wi-Fi 和 TCP 提示也改为使用实际命令结果。联网指令、延时、重试次数及控制逻辑沿用原流程。

## 串口约定

进入和返回使用字地址 `0x0680`，键值分别为 `0001`、`0002`。诊断数据从 `0x0688` 起连续占 11 个 8 字文本槽，按页面顺序发送。主控用 `0x82` 一帧写入，进入主循环时先同步一次，开页请求时立即刷新，停留期间约每秒刷新，返回后结束诊断页周期发送。换板可复用页面和字地址，由新板提供复位原因、联网结果和采集有效位。
