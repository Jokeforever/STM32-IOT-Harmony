# 为 VGUS 串口屏预留 USART1

用户用 DLB07 完成了串口屏独立测试。电脑曾读到版本寄存器 0x00 的有效回包，返回值 0x50 对应 V5.0。

STM32 保留 USART1 初始化和中断入口，使用 PA9 TX、PA10 RX，配置为 115200、8N1。格式化打印通过 `UsartPrintf()` 发送时，目标为 USART1 就提前返回。主循环启动部分和接收完成回调里的旧单字节接收已移除。原始串口收发接口供后续屏驱动使用。

USART2 继续接收 ESP8266 数据，USART3 继续接收 CO₂ 数据。

## 自动检查

通过实际串口源文件与模拟 HAL 验证，旧代码会发送 USART1 日志，改动后 USART1 不再格式化或发送日志，也不再续接旧接收。USART2 串口收发和 USART3 有效 CO₂ 帧接收通过。

13 套固件主机回归通过。控制集成共 395 项断言。Keil 完整重编译为 0 错误、5 条既有 cJSON 警告。

## 实物复验

1. 用 Keil 烧录真实工程的 `MDK-ARM/IOT/IOT.hex`。
2. 如需检查串口静默，只把 USB 转 TTL 的 RX 接 PA9，并共地。上电联网和上报期间，串口助手应收不到 STM32 的调试文本。
3. 核对 OLED 照常显示、Wi-Fi 与 OneNET 照常联网和上报。如果已接 CO₂ 模块，核对其读数照常更新。

用户确认 USART1 预留版本的实物复验通过。 STM32 发送温湿度到屏幕将作为下一步验证。
