# 当前项目完成进度总结

最后更新：2026-10-31。

## 当前基线

运行平台仍为STM32F103C8T6、ESP8266、24C02与HarmonyOS App；使用OneNET旧版物模型。
主循环裸机运行，尚未引入RTOS。App首页版本标记v13，配置格式v2。

- 新界面已预览；用户确认长截图中的重复、断层属于截图拼接，实际页面正常。

## 本轮改动

1. 温度和CO2请求统一决定风扇输出，报警处理不再覆盖。
2. 低温继电器正常/高温/温度无效时明确关闭，PB5/PB6初始化为关闭电平。
3. LED新配置默认目标统一200，已有EEPROM值优先；按真实dt计算，长间隔重建历史，负PWM限幅。
4. 水泵模式1命名为脉冲灌溉，水量准确标注为估算补水量。
5. App首页、详情页统一深绿/薄荷绿/暖白风格，增加公共组件与本地图标。
6. 全部属性可展开，错误可展开详情，图表和小屏数值适配。
7. 仓库Keil工程补齐middleware构建条目，新增主机回归测试。
