# VGUS 灌溉设置

2026-11-16 用户确认本轮实物复测通过。原 [SmartGrow-VTc 工程](../vgus/SmartGrow-VTc/SmartGrow-VTc.vt)新增第 2 页「灌溉设置」，可从「设备状态」进入并返回。滑条分别设置干旱阈值 BL 和湿润阈值 BH，范围均为 0% 到 100%。

## 调节和回显

进页时，STM32 将当前配置写入两个滑条。页面分别显示「生效」和「待应用」。拖动滑条只改屏幕上的待应用值。点「应用」后，STM32 请求一次读取两个待应用值，在 500 ms 内接收完整应答后，用 `AppCommands_Execute()` 成对校验和应用。返回再进入会重新载入当前生效值。

合法组合要求 `0 ≤ BL ≤ BH ≤ 100`。例如从 25% / 80% 改到 85% / 95%，两项按最终组合校验。BL 大于 BH 时提示「干旱高于湿润」，保留先前的生效值。读取超时也保留原配置。生效后，下次估算补水量时会使用新阈值，24C02 保存仍由现有延时写入流程处理。

## 串口地址

| 字地址 | 内容 |
|---|---|
| `0x0340` | BL 待应用值 |
| `0x0341` | BH 待应用值 |
| `0x0342` | 进入 `0001`、应用 `0002`、返回 `0003` |
| `0x0350` | 应用结果或读值提示 |
| `0x0358` | BL 生效值 |
| `0x0360` | BH 生效值 |

主控使用 `A5 5A 04 83 03 40 02` 读取一对待应用值。打开页面时才写入滑条初值，后续收到 App 或按键的设置时更新生效值。照明和水泵控制按键沿用原地址。 [状态页协议](34-VGUS-Pump-Touch-and-Mode-Markers.md)
