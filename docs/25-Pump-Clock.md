# 水泵毫秒时钟适配

水泵毫秒时钟适配经用户复验通过。

水泵模块使用 `PumpPort_NowMs()` 读取 32 位毫秒计数。F103 板级实现通过 `HAL_GetTick()` 提供时间。以后换板，在板级适配中提供同样的毫秒时钟，并由周期定时器每 10 ms 调用一次 `Bump_OnTimerTick()`。

自动灌溉用毫秒时钟判断是否超过 30 秒的检查间隔，脉冲模式用它判断 0.5 秒开泵和 1.5 秒停泵的边沿。灌溉总时长仍按 10 ms 的定时器回调次数累计。计数从最大值回到 0 后，使用无符号时间差继续判断经过时间。

## 自动检查

13 套固件主机回归通过。控制集成共 376 项断言。Keil 完整重编译为 0 错误、5 条警告。 目标大小为 `Code=50970 RO-data=6650 RW-data=208 ZI-data=7952`。

同一套控制回归在迁移前后均通过。覆盖自动模式在经过 30,000 ms 和 30,001 ms 时的启动判据，以及计数回绕时的脉冲关泵、再次开泵和自动模式启动边界。

## 烧录后实物复验

烧录真实工程的 `MDK-ARM/IOT/IOT.hex`，逻辑分析仪 D7 接 PB1。沿用土壤湿度 0%、BL=25%、BH=80% 的条件。

| 复验项 | 预期 |
|---|---|
| 上电关泵 | 保存关闭模式后断电重启，PB1 保持低电平。 |
| 脉冲灌溉 | D7 约 0.5 秒高、1.5 秒低，约 22 秒总计时结束后保持低电平。 |
| 自动灌溉 | D7 单次高电平约 22 秒，到时拉低。 |
| 运行中关泵 | 在 D7 高电平时切到关闭模式，确认 PB1 拉低并保持。 |

回绕边界由主机回归检查。实物复验用 D7 波形确认新固件的正常灌溉时序。

## 本轮验收结果

用户确认四项 D7/PB1 复验均通过，覆盖上电关泵、脉冲灌溉、自动灌溉到时关泵和运行中关泵。

D7 波形以 0.5 秒开泵、1.5 秒停泵及自动模式单次约 22 秒高电平为对照判据。30 秒启动边界和计数回绕由主机回归覆盖。
