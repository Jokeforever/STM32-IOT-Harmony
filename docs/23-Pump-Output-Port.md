# 水泵板级输出适配

水泵输出适配已通过四项 PB1 信号实测。

`mw_pump_port.h` 声明 `PumpPort_Set()`。F103 的 `app_pump_port.c` 将请求映射到 PB1，0 写低电平关泵，非零写高电平开泵。接口每次只写一次 GPIO。`bump.c` 负责初始化、灌溉启动与模式关闭，`Key.c` 的 TIM1 回调负责脉冲切换和到时关泵。两个调用路径共用该接口。GPIO 初始化先将 PB1 预置为低电平，再配置为推挽输出。

换板时，在 `app_pump_port.c` 调整引脚和有效电平，在 GPIO 初始化中预置对应的关泵电平。

13 套固件主机回归通过。控制集成共 362 项断言。Keil 完整重编译为 0 错误、5 条警告。 新适配已纳入 Keil 工程。目标大小为 `Code=51026 RO-data=6650 RW-data=220 ZI-data=7956`。

## 烧录后实物复验

烧录真实 Keil 工程生成的 `MDK-ARM/IOT/IOT.hex`，沿用现有水泵驱动接线。测试前记录水泵模式和土壤湿度阈值，结束后恢复设置。传感器读数低于湿润阈值时才进入补水分支。用 PB1 波形可先验证控制输出，实际出水需要接泵确认。

| 复验项 | 操作与预期 |
|---|---|
| 上电关泵 | 将模式设为关闭并保存，断电重启。PB1 为低，水泵保持关闭。 |
| 脉冲灌溉 | 在有补水需求时启动脉冲模式。先开泵约 0.5 秒，再停约 1.5 秒。总计时到期时停止并回到关闭模式。 |
| 自动灌溉到时关泵 | 在有补水需求时进入自动模式，等到约 30 秒检查周期。水泵启动并在本次灌溉时长结束后关闭，模式仍显示自动。 |
| 运行中切到关闭 | 水泵运行时切换到关闭模式。PB1 应回到低电平，后续脉冲或计时事件不应重新启动水泵。 |

## PB1 实测结果

用户确认上电关泵和运行中切到关闭两项正确。逻辑分析仪 D7 接 PB1，土壤湿度读数为 0%，BL=25%，BH=80%。脉冲模式记录到 11 个高脉冲，游标实测开泵 0.5 秒、停泵 1.5 秒，脉冲结束后保持低电平。关闭模式持续低电平。自动模式的完整高电平实测 22 秒，随后关泵并在下一周期再次启动。

按程序使用的流量 1.2 L/min，BL 与 BH 的差值对应 0.44 L 估算补水量和 22 秒计时。脉冲模式的计时包含停泵间隔。

本轮四项 PB1 控制信号复验通过。实际出水和结束后界面显示的模式待实物确认。
