# VGUS 告警与动作原因

2026-11-17 用户确认本轮实屏复验通过。首页第 13 页增加「告警」计数，点按进入第 14 页。新页显示光照、土壤湿度、CO₂、温度的当前读数、生效阈值和判断结果，底部显示风扇原因与加热状态。

## 判断依据

| 项目 | 显示依据 |
|---|---|
| 光照 | 低于下限为偏暗，高于上限为偏亮 |
| 土壤湿度 | 低于干旱阈值为偏干，高于湿润阈值为偏湿 |
| CO₂ | 读数有效且高于 CO₂ 阈值时显示超限 |
| 温度 | 使用温控状态机的通风、加热需求，分别保留已有的 1℃ 回差 |

风扇有两个独立触发来源，高温和 CO₂ 同时超限时显示两种原因。高温通风开启后维持到通风上限减 1℃，加热开启后维持到加热下限加 1℃。低温加热与 CO₂ 通风可以同时进行。加热状态读取主控输出引脚，负载是否发热仍需现场观察。

首页对四个监测项分别计数，每项最多计一次。温度或 CO₂ 采集无效时显示「--」及「无有效值」，计数只统计阈值告警。光照和土壤湿度仍按采集值与阈值比较。告警页为只读，参数调整继续在原设置页完成。

## 串口约定

USART1 沿用 115200 波特率。主控完成首轮采集并更新温控与告警判断后，由 `Vgus_UpdateAlarms()` 写入页面数据。每个字段占 8 个字，字符使用 ASCII 或 GB2312，沿用原文本结束符。

| 变量字地址 | 字段 |
|---|---|
| `0x03E0` | 首页告警数 |
| `0x03E8`、`0x03F0`、`0x03F8` | 光照读数、阈值、状态 |
| `0x0400`、`0x0408`、`0x0410` | 土壤读数、阈值、状态 |
| `0x0418`、`0x0420`、`0x0428` | CO₂ 读数、阈值、状态 |
| `0x0430`、`0x0438`、`0x0440` | 温度读数、阈值、状态 |
| `0x0448`、`0x0450` | 风扇原因、加热状态 |

主控以一条 246 字节的 `0x82` 报文同步所有字段。运行时以 200 ms 为最短检查间隔，变化时发送，约每秒补发。屏幕单独重启后可重新接收这组状态。换主控时可保留页面、字地址、编码和规则，重新接入串口和主控输出状态。
