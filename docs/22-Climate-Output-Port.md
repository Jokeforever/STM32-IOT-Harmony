# 风扇和加热器的板级输出适配

2026-11-13。风扇和加热器输出适配经用户实物复验通过。上一轮风扇和加热片五项实测是本轮对照基线。

`mw_climate.c` 根据温度和 CO₂ 计算两个开关请求。`Monitor_Temp()` 将请求依次交给 `ClimatePort_SetFan()` 和 `ClimatePort_SetHeater()`。接口在 `mw_climate_port.h` 中声明，`app_climate_port.c` 将请求映射为本板电平。

| 接口 | 引脚 | 关闭 `0` | 开启（非零） |
|---|---|---|---|
| `ClimatePort_SetFan()` | PB5 | 高电平 | 低电平 |
| `ClimatePort_SetHeater()` | PB6 | 高电平 | 低电平 |

启动时，`MX_GPIO_Init()` 先预置 PB5、PB6 为高电平，再启用推挽输出。`JDQ_Init()` 重置温控状态并关闭加热器，接着 `FAN_Init()` 关闭风扇。运行时每次调用先写 PB5，再写 PB6。两个接口均表达开关请求，实物状态由风扇转动、加热片端电压或电流确认。

换板时，在 `app_climate_port.c` 设置新引脚和有效电平，并在新板 GPIO 初始化中预置对应的关闭电平。

| 复验项 | 预期 |
|---|---|
| 高温通风回差 | 超过 `TH` 开风扇，降到 `TH` 保持开，降至 `TH−1℃` 关闭。CO₂ 保持未超限。 |
| 低温加热回差 | 低于 `TL` 开加热，升到 `TL` 保持开，升至 `TL+1℃` 关闭。 |
| CO₂ 独立通风 | 温度无通风请求时，有效 CO₂ 超限开风扇，回到阈值及以下关闭。 |
| 同时通风和加热 | 有效温度低于 `TL` 且有效 CO₂ 超限，两路同时开启。 |
| 温度失效处理 | 沿用上轮已验证的方法触发温度失效，加热应关闭。有效 CO₂ 仍超限时，风扇继续运行。 |
