## 状态字段

| 字地址 | 字段 | 显示与数据来源 |
|---|---|---|
| `0x0300` | 照明模式 | 关闭 / 手动 / 自动，来自运行配置 |
| `0x0308` | PWM 占空比 | 例如 `30.0%`，来自最近成功设置的占空比，关闭模式显示 `0.0%` |
| `0x0310` | 水泵模式 | 关闭 / 脉冲灌溉 / 自动，来自运行配置 |
| `0x0318` | 水泵输出 | 开启 / 关闭，PB1 高电平表示开启 |
| `0x0320` | 风扇输出 | 开启 / 关闭，PB5 低电平表示开启 |
| `0x0328` | 加热器输出 | 开启 / 关闭，PB6 低电平表示开启 |

模式取自运行配置，输出取自 STM32 的控制引脚。例如水泵处于自动模式且等待灌溉时，两格分别显示「自动」和「关闭」。输出栏反映控制信号，负载是否实际运行要在负载端确认。

`Vgus_UpdateActuators()` 在主循环更新输出后检查状态，检查间隔约 200 ms。状态发生变化时发送，值相同约每秒重发一次，发送失败后按检查周期重试。USART1 用一条 102 字节的 `0x82` 报文从 `0x0300` 连写六格。每格占 8 个字，以 `FF FF` 结束并覆盖整个槽。中文用 GB2312，数字占空比用 ASCII。 [中显 VGUS 开发指南](https://www.viewtech.cn/UploadFile/EditorFiles/VGUS-DevelopmentGuide.pdf)

## 编译和下载

1. 在 VGUS2026 中打开现有的 [SmartGrow-VTc 工程](../vgus/SmartGrow-VTc/SmartGrow-VTc.vt)。两个页面共 12 个文本控件，开机页为 0，各值初始显示 `--`。状态页中文使用随工程归档的官方 VTc 480×272 示例 34 号 24 点阵字库。
2. 确认首页按钮的「页面切换」目标为 1，状态页返回按钮的目标为 0。串口设置为 TTL/CMOS、115200、8N1，帧头 `A5 5A`，CRC16 关闭。按 F7 编译。
3. 将生成的 `VT_SET_VTc` 放到 FAT32 TF 卡根目录。屏断电插卡，上电等待下载完成，断电拔卡后重新上电。固件通过 PA9（USART1 TX）接屏 DIN，两端 GND 共地。

- VGUS2026 编译及虚拟屏双向切页通过，随后用户确认实屏复验通过。
- Keil 完整重编译为 0 错误、5 条既有 cJSON 警告。13 套主机回归通过，另核对状态帧、GPIO 输出极性、失败重试、定时重发、时钟回绕和环境页六项报文。
