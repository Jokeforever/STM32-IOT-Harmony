# App 界面美化记录（2026-10-31）

## 风格与结构

统一使用深绿、薄荷绿、暖白，配合本地 SVG 线性图标。

- 首页：环境总览大字温湿度、独立同步时间、刷新工具栏、光照/CO2/土壤速览、设备入口和模式摘要。
- 详情：设备信息、环境读数、照明/灌溉、阈值、趋势、采集状态及可展开的全部属性。
- 没有读到属性时展示 `--`，避免把未读取状态表示为0。
- 未收到上报时间时，状态标注为“未确认”；已有在线判断算法保持不变。
- 鉴权失败显示可理解的说明，展开“详情”可以查看原始错误。

## 关键文件

- `entry/src/main/ets/theme/AppTheme.ets`：配色。
- `entry/src/main/ets/components/MonitorComponents.ets`：状态标签、卡片、错误提示、刷新工具栏等。
- `entry/src/main/ets/pages/Index.ets`：首页布局。
- `entry/src/main/ets/pages/DeviceDetail.ets`：详情布局、阈值按钮和图表。
- `entry/src/main/resources/base/media/monitor_*.svg`：本地图标，无外部图片请求或依赖。

## 保留与适配

请求、控制、缓存、刷新方法已与改动前逐段比对，内容保持一致。
OneNET 标识符、LED/水泵模式值、10秒刷新周期和30秒在线判断未调整。
动态显示继续使用 @Prop 组件，全部属性继续以 identifier/value/time 生成行key。
加减按钮为44×44，使用独立Text符号和零内边距，避免文字裁切。
趋势图按容器实际宽度绘制；首页小卡片把单位放在独立一行，减轻长读数拥挤。
估算补水量在卡片中保留两位小数，全部属性可查看原始精度。
